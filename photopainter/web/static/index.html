How to create an API key in Immich?
  1. In Immich, click your avatar (top right) → Account Settings.
  2. Tab "API Keys" → "New API Key", name it "photopainter".
  3. Check only these permissions:
    • album.read
    • asset.read
    • asset.download
  4. No write/admin permission needed.
  5. Click Create, then copy the key (shown once).
  6. Paste it above and save.

Quiet hours

Pause the refresh during quiet hours (e.g. at night). Set start > end to wrap midnight (e.g. 22 → 6 pauses from 22:00 to 06:00).

Frame orientation

0° / 180° = portrait, 90° / 270° = landscape. Affects the logical canvas (480×800 or 800×480) and how photos get cropped.

Local cache

Downloaded photos are cached. If Immich is unavailable, the frame uses the cache. Old entries are auto-purged every night at midnight.
