How to create an API key in Immich?
  1. In Immich, click your avatar (top right) → Account Settings.
  2. Tab "API Keys" → "New API Key", name it "photopainter".
  3. Check only these permissions:
    • album.read
    • asset.read
    • asset.download
  4. No write/admin permission needed.
  5. Click Create, then copy the key (shown once).
  6. Paste it above and save.
